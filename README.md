# Winter Arc 2026 ❄️

Winter Arc 2026 is a personal productivity and habit-tracking web app built to help users stay consistent with their goals and daily routines.

The idea is simple — set your goals, complete your daily tasks, track your progress, and stay consistent throughout the Winter Arc.

## What you can do

* Create and manage daily goals
* Track habits and daily activities
* View your overall progress
* Keep track of completed tasks
* Monitor your consistency
* Use the app on desktop or mobile

## Built With

* React
* TypeScript
* Vite
* CSS
* JavaScript

## Getting Started

To run the project locally, first clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Move into the project folder:

```bash
cd winter-arc-2026
```

Install the required packages:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal to use the application.

## Build

To create a production build:

```bash
npm run build
```

You can preview the production build with:

```bash
npm run preview
```

## Environment Variables

If the project uses any API or external service, create a `.env` file in the root directory.

Keep private keys and API credentials inside this file.

Example:

```env
VITE_API_KEY=your_api_key_here
```

Do not upload your actual `.env` file or API keys to GitHub.
